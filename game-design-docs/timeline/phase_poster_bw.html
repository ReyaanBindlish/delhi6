HOW NINE WEEKS WORKS

Worlds are generated from real maps, so the team's time goes into systems and story. Systems land first because the story is told through them. Karachi, half the game, is built before Delhi. Every Sunday ends with a playable build and a milestone review.

CUT LINE · IF A MILESTONE SLIPS

  1. Side content: tea stall, cricket, Kasur trip
  2. Act 3 farm and route in as cinematics
  3. Delhi hubs reduced to playable interiors
  4. Crowds limited to 12 archetypes
  5. Part 2 Wapsi as a later release

RULES OF ENGAGEMENT

A phase is done only when its exit criterion is met in a playable build. One engine version for the whole project. 60 fps on an RTX 3070 at every milestone. Real places; fictional brands and people. If two milestones slip in a row, apply the cut line from the top.
